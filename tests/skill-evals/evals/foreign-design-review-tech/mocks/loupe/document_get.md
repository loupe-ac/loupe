{"documentId":"01doc000-0000-7000-8000-000000000042","title":"Tech design: Count the distinct words","status":"draft","version":2,"tags":["tech-design","decisions"],"content":"## At a glance\n\nThe card body is the requirement source, because the owner skipped product design. The change adds `unique_words` to `tally/counter.py`.\n\n## Problem\n\nThe library counts words, and it cannot count the distinct ones. The card asks for a distinct count that treats `Word` and `word` as one word.\n\n## Current state\n\n`count_words` in `tally/counter.py` already lowercases its input and splits it on white space, so `unique_words` can reuse its normalisation.\n\n## Solution\n\n`unique_words(text)` calls the same split as `count_words` and returns the size of the set of words. No other file changes.\n\nDepends on: none.\n\nDeploy notes: none. The change adds no dependency, migration or setting.\n\n## Strengths and weaknesses\n\nStrength: one short function. Weakness: a large text builds a set in memory.\n\n## Alternatives\n\nA counter object would also give the frequency of each word, which the card does not ask for.\n\n## Testing\n\nA unit test passes `a A b` and expects 2.\n"}
