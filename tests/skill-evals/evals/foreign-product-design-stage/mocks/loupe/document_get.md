{"documentId":"01doc000-0000-7000-8000-000000000041","title":"Product design: Count the distinct words","status":"in-review","version":1,"tags":["product-design"],"content":"## At a glance\n\nA developer who uses the tally library can count the distinct words of a text with one call.\n\n## Problem\n\nA developer who wants to know how many different words a text holds must build a set by hand, because the library only counts every word.\n\n## Current behaviour\n\n1. The library counts the words of a text with `count_words` in `tally/counter.py`.\n2. The library has no call that counts distinct words.\n\n## Proposed behaviour\n\n1. R1: The library offers a call that returns the number of distinct words of a text.\n2. R2: Two words that differ only in case count once.\n\n## Out of scope\n\n1. Counting the frequency of each word.\n\n## Scenarios\n\n1. S1 (R1): A developer passes `a b a` and gets 2.\n2. S2 (R2): A developer passes `a A b` and gets 2.\n"}
