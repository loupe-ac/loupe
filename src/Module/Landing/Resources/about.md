I am Geoffrey Bachelet, and I build Loupe alone. No company stands behind it. This page says why I built it and why I think it will last.

## Why I built it

I was tired of watching a row of Claude Code sessions in terminal windows. The workflows wrote many Markdown files, and I could not read them well. I had no good way to mark a passage or send feedback on it. So the first version of Loupe was a document reviewer.

Then I saw that I also wanted to review the end result, not only the documents. So I added live review, where I mark the running app and the feedback goes back to the agent.

Then I saw that I still juggled terminals when I built features in parallel. So I added the board, and Loupe grew from there.

I build Loupe with Loupe, and I use it every day to build my other apps too.

## How Loupe lasts

Three things keep Loupe going.

1. The hosted plan is how Loupe pays for itself.
2. Loupe is open source under the AGPL licence, and you can host it yourself. If I stop, the code stays usable by anyone.
3. I use it every day, for Loupe and for my other apps. I need it to keep working.
