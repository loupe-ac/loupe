- (#1368) — **Changed:** Approving a design now closes its inbox ask within seconds, also while the board evaluates many cards, because the messages a person waits on run on a new `interactive` queue. A self-hosting operator with a custom worker command must add `interactive` after `scheduler_default`: `php bin/console messenger:consume scheduler_default interactive card_eval jobs`. A worker that does not read it never runs those messages.
