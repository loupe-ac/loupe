- (#1286) — **Changed:** the agent review check is now named `Loupe / Agent review` and the live review check `Loupe / Live review`. Loupe renames the check on the current head of each open pull request once, at its next evaluation of the card. A check on an older head keeps its old name. A GitHub ruleset that requires `loupe/agent-review` or `Loupe live review` by name waits for a check that never comes, so update the ruleset to the new names.
