- (#PENDING-1290) — **Added:** The public API now has document routes under `/api/v1/projects/{project}/documents`: list, create, read and change a document, send a draft to review, and list, read and submit versions. A create or a revision takes an `Idempotency-Key`. The list takes `limit` up to 200 and the filters `status`, `tag`, `series`, `q` and `includeArchived`.
