- (#1108) — **Changed:** The background queues are now named `card_eval`, `card_sweep` and `jobs`, and the queue chart in Sentry shows the same names. A self-hosting operator with a custom worker command must run `php bin/console messenger:consume scheduler_default card_eval jobs` and `php bin/console messenger:consume card_sweep`. The old names fail with an unknown transport. A message that waits under an old name during the upgrade is lost.
